# SixthPhysics

Static GitHub Pages deployment for **SixthPhysics** — an interactive pre-university physics questionbank with **7,643 solver-verified questions** across **IB Physics 2025 (SL/HL)**, **UK A-Level**, and **NCUK IFY**.

## Links

- **Live Practice App:** https://sixthphysics.github.io
- **Source Code:** https://github.com/sixthphysics/sixthphysics
- **Hugging Face Model (`Qwen/Qwen3.5-9B` LoRA):** https://huggingface.co/d4ydy/sixthphysics-qwen3.5-9b-lora
- **Hugging Face Dataset & Benchmark:** https://huggingface.co/datasets/d4ydy/sixthphysics-bench-and-bank

## Deployment Notes

This repository hosts the static Next.js export (`dist-pages/`) served via GitHub Pages (`.nojekyll` enabled for `_next/` assets and `sixthphysics-data/` question chunks). Please open issues and pull requests in the [main source repository](https://github.com/sixthphysics/sixthphysics).
